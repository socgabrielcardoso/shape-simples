# Project Profile

**Shape Simples** is a lightweight browser-based computer-vision laboratory for hand-shape recognition and visual-state experimentation using webcam input.

## What this project demonstrates
- Real-time browser video processing
- Hand-landmark geometry
- MediaPipe integration
- Privacy-aware local processing
- Lightweight frontend experimentation without a dedicated backend

## Portfolio signal
This repository demonstrates rapid experimentation with computer vision while keeping execution simple, local and easy to reproduce.

**Domain:** Computer Vision, Browser ML  
**Stack:** HTML, CSS, JavaScript, MediaPipe  
**Status:** Technical laboratory
